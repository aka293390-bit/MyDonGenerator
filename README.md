# まいどん生成機・ブラウザー版（ニジイロ試作）

このフォルダーの中身をGitHubリポジトリのルートへ置き、GitHub Pagesを有効にすると動作します。`index.html`、`niji.js`、`pkg/`は同じ配置のままにしてください。

## 使い方

1. ページを開き、「モデル一式のZIPを選ぶ」から素材ZIPを選択します。展開済みの素材フォルダーを選ぶ方法もあります。
2. モデル一覧から`.numdlb`を選びます。読み込み時に必要なメッシュ、材質、骨格、テクスチャだけを展開します。
3. マウスまたはタッチでプレビューを回転し、PNGを保存できます。

モデル素材はページへアップロードされず、ブラウザー内で処理します。ZIPを選んだときはZIP内のファイル一覧だけを登録し、モデル本体を表示する際に参照素材だけを解凍します。

## 現在の対応

ニジイロの`.numdlb`からSSBHのモデル、メッシュ、材質、骨格情報を読み込みます。`.nutexb`は素材ZIPで確認したRGBA8とBC3形式をデコードします。グリーンの`.nud`と`.nut`の従来プレビューも残しています。

アニメーション再生、複数モーションからの自動連番生成、元アプリと同等のパーツ別色マスク編集は未対応です。ブラウザー上で外部CDNのThree.jsとJSZipを読み込むため、初回表示時はインターネット接続が必要です。

## 構成・ライセンス

`pkg/`はRust製SSBH解析コードをWebAssemblyへコンパイルした成果物です。SSBH形式の解析には[ultimate-research/ssbh_lib](https://github.com/ultimate-research/ssbh_lib)のMITライセンスのコードを利用しています。ライセンス文は`LICENSES/ssbh_lib-MIT.txt`に同梱しています。
